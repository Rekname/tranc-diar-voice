**Группа:** СПК-КБ-231

**Вид проекта:** Курсовая работа

Десктопное приложение для автоматической транскрипции и диаризации спикеров в русскоязычных аудиозаписях методами **faster-whisper** и **NVIDIA NeMo**.

>**Запуск только на Linux или macOS.** NVIDIA NeMo официально не поддерживается на Windows: часть зависимостей (`triton`, специфические сборки `pynini`/`sentencepiece`) на Windows не собирается. Пользователи Windows могут запустить проект через **WSL2** (Ubuntu) — приложение работает оттуда без изменений.

## Возможности

- **Транскрипция** — распознавание русской речи моделями faster-whisper пяти размеров (tiny / base / small / medium / large-v3) с опциональными пословными таймстомпами
- **Диаризация** — определение «кто и когда говорит» через NVIDIA NeMo (titanet_large + vad_multilingual_marblenet) с тремя пресетами сложности (лёгкая / средняя / тяжёлая)
- **Редактор результатов** — просмотр и правка JSON-расшифровки: переименование спикеров, редактирование текста реплик, мгновенная подсветка по цветам
- **Сохранение в JSON** — каждый прогон сохраняется в `results/<имя_файла>.json` с разметкой по интервалам, спикерам и языку

## Требования

- Python **3.10–3.12**
- ОС: **Linux** / **macOS** (на Windows — только через WSL2)
- [uv](https://docs.astral.sh/uv/) — рекомендуемый менеджер пакетов
- **ffmpeg** в системе (для конвертации аудио)
- ~6 ГБ свободного места под модели (Whisper + NeMo)

## Установка

### Вариант 1 — через uv (рекомендуется)

```bash
git clone https://github.com/Rekname/tranc-diar-voice
cd tranc-diar-voice
uv sync
uv run hf download Rekname/tranc-diar-voice-models --local-dir models/
```

### Вариант 2 — через pip

```bash
git clone https://github.com/Rekname/tranc-diar-voice
cd tranc-diar-voice

source .venv/bin/activate

pip install -r requirements.txt
hf download Rekname/tranc-diar-voice-models --local-dir models/
```

## Использование интерфейса

Приложение открывается единым окном с верхней панелью кнопок и боковой панелью настроек справа.

### Обработка аудио

1. Нажмите **«Файл…»** и выберите аудиозапись
2. В правой панели **«Настройки»** выберите:
   - **Модель** Whisper (по умолчанию `small`)
   - **GPU** — если доступна CUDA (на CPU-сборке заблокирована)
   - **Диаризация** — уровень сложности (по умолчанию «Средняя»)
   - **Точные таймстампы слов** — повышает качество границ ценой замедления ~×2
3. Нажмите **«Обработать»** — в окне будет виден прогресс по этапам:
   - конвертация WAV 16k
   - транскрипция Whisper
   - диаризация NeMo
   - объединение
4. По завершении результат отображается в виде карточек спикеров и автоматически сохраняется в `results/<имя_файла>.json`

### Просмотр и редактирование JSON

1. Нажмите **«Отобразить»** и выберите любой JSON из `results/`
2. Сверху появится список спикеров — переименуйте их, имена сразу применятся во всех карточках
3. Отредактируйте текст любой реплики прямо в карточке
4. Нажмите **«Сохранить»** — изменения запишутся в исходный JSON
